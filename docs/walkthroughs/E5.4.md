## §0 — The architecture rule, and the two proposals

**The honesty content lives in the served presentation model; the page only
renders it.** E5.3's first draft composed option states in the page and
shipped a wrong label invisible to every test — at LABEL stakes. A page
composing its own verdict banner from raw manifest fields would repeat that
at VERDICT stakes. So every banner string, reason list, failing set, expiry
condition and explanation below is a field of `build_viewer_model`'s
output, the mutations run at that layer, and the page's JavaScript contains
no sentence of its own about the run.

**Decision 3 — the uncertainty is not optional: option (c)+.** The readout
always carries the paired half with its semantics (E5.3; mutation V2 stays);
the prediction layer's legend ALWAYS shows the paired σ range and method
(`paired_legend`, mutation H3); no toggle, no suppression path exists in the
page (asserted by grep). **The map pixels are univariate BY CHOICE**, and the
pairing is protected by the single export file (E5.2), the readout, the
legend, and the absence of any way to hide it. **Option (b) — σ as colour
saturation — was considered and DECLINED**, and the reason is recorded in
the model's own `pairing_rule`: it would encode three different KINDS of
spread (a sample SD, a kriging model sd, a QRF quantile half-width) as one
visual channel — the cross-kind conflation obligation 7's semantics column
exists to prevent, made visual — and with decision 4's hatch delivering the
map-level honesty, (b)'s remaining value was continuous σ-gradation inside
the informed region: 34 cells, invisible at any zoom.

**Decision 4 — the 99 % fact on the map: option (ii).** The model derives a
per-cell no-information boolean from RECORDED values only — the 35 stations
and the fitted range 21.611 km, both from the manifest through the catalog
(one pass-through added: `full_data_fit` now reaches the model) — and the
page draws diagonal stripes OVER the colour on those cells, default ON for
every layer. **Shape-not-value** (the bins precedent): a geometric function
of recorded values, computed in the tested model, never in the page, and
never a measurement. **The two labels, per layer**, verbatim from the model:

- on the range-source layer — *beyond one fitted variogram range (21.6 km; a
  LOWER BOUND — the fit sat at the candidate ceiling) of every station: this
  model carries no information here; 2,846 of 2,880 predictable cells. Drawn
  at its largest defensible extent.*
- on every other layer — *no station within 21.6 km (the fitted range of
  Prediction (μ) · Ordinary kriging): spatial support is absent here for any
  model — distance to data is not this layer's information measure, and no
  variogram is implied.*

The direction is stated in the model: at the candidate ceiling the true
range is at least the fitted one, so the informed region is at least as
large as drawn — marking beyond-fitted-range as no-information overstates
ignorance, the conservative direction for claims. **The contour is not
stroked** (my judgment): the hatched region's own edge is the
one-fitted-range boundary, and a stroke would add a polygon derivation with
no new value. **The mask is never marked**: the API reads the range-source
layer's export once and hands the model the predictable flags, so the count
is of predictable cells and a masked cell is the mask, not "no information".

**Two confirmations, as given:** the `full_data_fit` pass-through is one
line (`_layer` returns it; tested by equality with the catalog); the
surface's expiry is served as *"stated in the reason text"* with the reason
string verbatim — no parsing, no invented field, E5.1's asymmetry rule
holding under pressure to normalise it (a surface's reason has no
`lifted_by`; the test asserts the key is absent).
