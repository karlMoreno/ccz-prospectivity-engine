## b — The enum and the propagation rule

**Standing P2.0 decisions (Karl, 2026-08-08) — recorded here because
`origin.py`'s docstring cites this section:**

1. **LITERATURE is its own enum member** — five values. Its evidence bar is a
   citation specific enough to LOCATE the number (document +
   table/section/page); "TS-6" alone is insufficient. The `ts6_finding`
   strings in covariates.yaml already fail that bar; P2.0c reports them as
   evidence gaps rather than closing them by guessing.
2. **`author: unrecorded` is admissible only for values predating the rule**;
   P2.0d freezes the file list, so the set only shrinks. New work declares
   `model` or a named person.
3. **Origin is declared per entry**; file-level origin is computed by
   `combine_origins`, never hand-written. The corpus CSV gets no origin
   column.
4. **Nothing is renamed.** The `synthetic_*` / `src_synthetic_*` misnomer is
   recorded in docstrings, not corrected by renames.
5. **The declaration-based guard lands in P2.0d**; P2.0c widens the path
   predicates as interim cover only.

```
        engine/prospectivity/provenance/origin.py
   ┌───────────────────────────────────────────────────┐
   │  DataOrigin (str Enum)                            │
   │  MEASURED ─► DERIVED ─► LITERATURE ─► SYNTHETIC   │
   │                                      ─► AUTHORED  │
   │  most real ──────────────────────────► least real │
   │                                                   │
   │  ORIGIN_ORDER_MOST_REAL_FIRST  (the one ordering) │
   │  combine_origins([...]) ─► least-real input wins  │
   │  validate_author: "model" | named | "unrecorded"  │
   └───────────────────────────────────────────────────┘
        │ P2.0c: contracts declare data_origin per entry;
        │        file-level origin = combine over entries
        ▼ P2.0d: audit test walks the tree; production-path
                 guard + watermark derive from declarations
```

The ordering measures **provenance distance from a measurement this repo holds
and can hash — not trustworthiness**. DERIVED outranks LITERATURE because it
traces to a hashed input by a recorded formula; LITERATURE traces to a
publication with no file in hand. `combine_origins` returns the least-real
input (a real corpus does not launder a synthetic terrain) and serves two
scales with the same rule: artifacts → run, entries → file. Empty input
raises — a silent default is the failure mode the module exists to prevent.

**Deliberately not a pattern.** A value object with a monotone combine — no
Strategy, no Registry. One ordering exists and no second is coming, so a seam
would be indirection without a variation point (the PATTERNS.md §3 standard).
**PATTERNS.md is deliberately unchanged by this task** for that reason.

## d-2 — The declaration-plus-evidence production guard

**The rule.** A declaration is a CLAIM; a hash over real bytes is the PROOF.
Admissible on a production path ⇔ declared MEASURED in the source-queue
entry **and** the declared input file exists **and** the entry's recorded
`content_hash` is a real 64-hex SHA-256 matching a re-hash of those bytes.
Anything else refused BY NAME with the FIRST failing condition — including a
MEASURED declaration with pending evidence, which is the honest reading of
the `[06]` incident: not mislabelled, unproven. The enum stays at five: a
transient evidence condition is not an origin, and evidence completeness is
a separate check over the same declaration.

```
  build_*_adapter(source_id, path)
        │
        ▼
  _require_production_path(path)        ← P1 LOCATION rule, original
        │                                 {"tests","fixtures"} predicate
        ▼                                 restored (widening REMOVED)
  _require_proven_measured(source_id, path)
        │  entry = source_queue[source_id]
        ▼
  measured_evidence_failure(entry, path)   ← ONE owner, shared:
    1 declared MEASURED?                     corpus_builder RAISES on it,
    2 recorded hash real 64-hex, not null?   _backed_by RECORDS its outcome
    3 file exists?
    4 re-hash(bytes) == recorded?
```

**SUBSUMES or COMPLEMENTS: COMPLEMENTS, deliberately — and the review made
