## P2.B — the investigation

**Question** (BACKLOG §1, standing since 2026-07-28): `[01]`'s published
event mass includes buried nodules a collector cannot recover; can
surface-only mass be derived from `[05]`'s per-nodule records?

**Method:** parse both real PANGAEA files; classify every `[05]` nodule by
`Depth sed [m]` (`0.000` = surface; positive values **and the string values
`">0.000"`/`">0.100"`** = buried — naive numeric coercion silently drops 23
buried nodules into NaN, the first trap; blank = unknown); reconcile buried
counts per event against `[01]`'s published `Nodules [#] (buried)`; sum
recorded surface masses and compare with published totals. (Second trap:
`Sample ID` has nulls, so row counts must use group size, not non-null
counts.)

**Findings, per the real files:**

```
  1,658 nodules / 36 events
  surface 1,431 · buried 212 (189 numeric + 23 ">…" strings) · unknown 15
  buried counts [05] vs [01]:  30 of 36 events AGREE
  the 6 disagreements: ALL SO268/2 —
      2_182-1  [05] says 0 buried   [01] publishes 24
      2_116-1  [05] says 0          [01] publishes 15
      2_181-1  [05] says 3          [01] publishes  7
      2_166-1  [05] says 1          [01] publishes  6
      2_175-1  [05] says 0          [01] publishes  4
      2_95-2   [05] says 6          [01] publishes  4
  cleanly derivable events (no unknown depth, all surface masses): 20 of 36
  surface/published mass ratio: median 0.96 · min 0.09 (SO268/2_149-1:
      surface 0.37 kg vs published 4.1 kg — the 73%-buried-count event,
      ~11x disagreement BY MASS; BACKLOG's "~3x" was a pre-P2.B estimate)
```

**Verdict (fixes the enum):**

- `total_as_published` — **ADMISSIBLE**: available for all 36 events,
  reconciled in E1.3, the published quantity.
- `surface_only_from_05_depths` — **EXCLUDED**: the depth column contradicts
  the published buried counts on 6/36 events exactly where burial is
  heaviest, so a depth-derived surface sum silently INCLUDES buried mass
  there; 15 unknown-depth nodules; only 20/36 events clean — a subset target
  shrinks n and mixes bases.
- `surface_by_subtraction_from_01` — **EXCLUDED**: `[01]` publishes buried
  COUNT, never buried MASS.

Surface-only stays the scientifically preferred target IF Track G resolves
the six-event contradiction — recorded as the concrete Track G question in
BACKLOG §1. Resolution arrives as a NEW admissible value, never a code edit.
